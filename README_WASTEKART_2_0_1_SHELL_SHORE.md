# WasteKart 2.0.1 — Shell Shore (Exact Asset Patch)

This patch installs **Coast Cup 1/4 — Shell Shore** using **exactly** the two user-provided files:

- `track_01.png` — exact provided artwork
- `track_01.mask.png` — exact provided road mask

The only generated file is `track_01.json`, which provides the route metadata needed by the game.

## Files included
- `WasteGame/assets/WasteKart/Tracks/Cups/Cup2/track_01.png`
- `WasteGame/assets/WasteKart/Tracks/Cups/Cup2/track_01.mask.png`
- `WasteGame/assets/WasteKart/Tracks/Cups/Cup2/track_01.json`

## Install
Copy these files into your repo and replace or add the existing Cup 2 Track 1 files.
