WasteKart 2.7.2 - Rainbow Rocket continuous bridge rebuild

INSTALL (existing GameHub / WasteKart installation)
- Extract the patch into your GameHub repository root.
- Replace WasteGame/wasteKart.py.
- Replace ALL six Rainbow Rocket PNGs included in this ZIP.
- Do not keep the old rainbow_rocket_track.png; it contains the rounded
  bridge-piece art. Changing the overlay alone cannot remove those caps.
- No changes to catalog.json, geometry, width profiles, respawn checkpoints,
  or power-up/amulet behavior are necessary.

The complete upgrade adds the original Rainbow Rocket sprites, metadata and
existing 1x amulet artwork for convenience. Other WasteKart cups and original
GameHub assets are still expected in their normal repository directories.

Why the change? The sausage-shaped bridge caps were baked into the *base track
image*, not just the above-kart overlay. A new rasterizer uses the unchanged
438-position 960x600 width/height profile to draw continuous rainbow tiles and
edge lines through both overpasses. All collision/fall/layer masks are generated
from the exact same geometry. The upper deck overlay is cropped directly from
those final map pixels for no differently-painted bridge strips.

Validation: compile, RGBA overdraw identity, both crossing masks, all 438
profile samples, kart-center and midroad positions, 19 respawn points per lap,
1-lap and 3-lap completion, forward rescue to safe roadway.
Full visual testing in Pygame/Pygbag still required.
