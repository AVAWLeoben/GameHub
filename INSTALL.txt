WasteKart 2.7.1 - Rainbow Rocket bridge repair and smaller item boxes

Extract this ZIP in the GameHub repository root; overwrite the existing files.

REQUIRED REPLACEMENTS
  WasteGame/wasteKart.py
  WasteGame/assets/WasteKart/rainbow_rocket/rainbow_rocket_deck_overlay.png

The Python file and deck overlay must be installed together. Otherwise the
old rounded bridge overlay may still appear. Rainbow Rocket's base track,
geometry, masks, cup registration, widths, and rescue points are unchanged.

Item-box collision radius: 23 -> 11.5 world pixels. Item boxes, floating
glints and collection animations are reduced to approximately half scale.
Existing turbo/tailwind graphics and four permanent player amulets unchanged.

Complete ZIP includes the previous 2.7.0 1x amulet artwork for easy setup.
The smaller patch ZIP includes ONLY the two required replacements.

Tested: syntax, six Cog Chompers, 438 track samples, both crossing masks,
pickup radius boundary tests, amulet test, 1- and 3-lap route progression.
Pygame and Pygbag visual validation still needs to be carried out on device.
