# WasteKart 1.4.3 — Kart Art Polish Pass

This is a small presentation-focused follow-up to 1.4.2.

## Changes
- Slightly larger in-race kart rendering for the new top-down kart artwork.
- Richer two-layer drop shadow under karts.
- Larger and more noticeable reflex-start flame effect.
- Corner player buttons now use more child-friendly iconography:
  - reflex buttons show a tap/hand symbol
  - item buttons show a large item icon with a simple player badge

## Install
Replace `WasteGame/wasteKart.py` with the included file and deploy as usual.
No asset changes are required beyond the kart art already installed from 1.4.2.
