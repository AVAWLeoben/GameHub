# WasteKart 1.4.2 — Corner Buttons and New Kart Artwork

This update makes two visual/UX changes:

1. Player action buttons (reflex start and power-up activation) are placed at the four corners of the playfield:
   - Player 1: top-left
   - Player 2: top-right
   - Player 3: bottom-left
   - Player 4: bottom-right

2. The temporary kart art is replaced by a new top-down kart sprite set derived from the supplied red kart artwork. The eight kart slots are recolored variants of that base image.

## Install

Merge the included `WasteGame/` folder into your GameHub repository, replacing:
- `WasteGame/wasteKart.py`
- `WasteGame/assets/WasteKart/Karts/kart_01.png` ... `kart_08.png`

Then commit and push to deploy.
