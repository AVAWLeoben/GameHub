# WasteKart 2.0.4 — Turtle Tides (Exact Asset Patch)

This patch installs **Coast Cup 4/4 — Turtle Tides** using **exactly** the two user-provided files:

- `track_04.png` — exact provided artwork
- `track_04.mask.png` — exact provided road mask

The only generated file is `track_04.json`, which provides the route metadata needed by the game.

## Files included
- `WasteGame/assets/WasteKart/Tracks/Cups/Cup2/track_04.png`
- `WasteGame/assets/WasteKart/Tracks/Cups/Cup2/track_04.mask.png`
- `WasteGame/assets/WasteKart/Tracks/Cups/Cup2/track_04.json`

## Install
Copy these files into your repo and replace the existing Cup 2 Track 4 files.
